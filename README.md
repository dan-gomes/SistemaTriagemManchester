# SistemaTriagemManchester

SistemaTriagemManchester é um aplicativo desenvolvido em windows forms com integração ao material design, projetado para oferecer uma interface moderna e amigável para realizar triagens com base no Protocolo de Manchester. A aplicação é organizada no padrão de camadas, utiliza algoritmos de classificação implementados em Python e conecta-se a um banco de dados PostgreSQL para o armazenamento de informações.
